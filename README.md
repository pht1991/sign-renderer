# Sign Renderer

A browser-based 3D sign / billboard mockup tool built with **React + Vite + Three.js**.
Layer and preview extruded sign faces, then export assets for fabrication or client previews.

Live demo: https://sign.phtbyte.com

## Stack
- React 18 + Vite
- Three.js for layered 3D sign rendering
- GitHub Pages deployment via `gh-pages`

## Develop
```bash
npm install
npm run dev      # local dev server
npm run build    # outputs to dist/
```

## Deploy
Push to the repo and let the GitHub Pages workflow publish `dist/` to `https://sign.phtbyte.com`.
